# ADR 0001: PDF generation with embedded Typst

- Status: accepted
- Date: 2026-10-28
- Task: T-0.9 (spike), relates to FR-FN-5, NFR-9

## Context

Invoices (FR-FN-5) must be rendered to PDF offline, on Linux, Windows and macOS,
with Cyrillic text, country-specific layouts (RU "Счёт на оплату", international
invoice, later US/UK) and optional images (logo, signature, stamp). Templates
should be easy to add per country without Rust layout code.

## Options

1. **Typst as a library** (`typst` + `typst-as-lib` + `typst-pdf`): templates are
   `.typ` files with data passed as JSON.
2. `genpdf` / `printpdf`: small, but every layout is hand-written in Rust, and
   tables and line breaks are limited.
3. WebView print-to-PDF: no cross-platform API in Tauri 2.

## Spike results

Measured on Linux x86_64 with the release profile (LTO, stripped), using
`cargo run --release -p crm-pdf --example probe`:

| Variant | Binary size added | gzip -9 | xz -9 |
|---|---|---|---|
| typst-kit embedded fonts (9.6 MB of fonts) | +41.5 MB | — | — |
| Own fonts: Noto Sans Regular + Bold (1 MB) | +32.9 MB | 13.6 MB | 9.8 MB |

- Rendering time: an A4 invoice with 30 table rows takes ~7–9 ms per render
  (the first render is ~18 ms because of warm-up). Output is ~50 KB.
- Cyrillic is rendered and extractable as text (covered by
  `passes_data_and_renders_cyrillic`).
- Most of the size is Typst itself (ICU data, hyphenation, bibliography
  support), not fonts.
- A clean release build of the crate takes about 3 minutes.

## Decision

Use Typst (option 1) in a separate crate `crates/crm-pdf`:

- `crm_pdf::render(template, data: serde_json::Value)`: data is available
  in templates as `json(bytes(sys.inputs.data))`.
- Only fonts bundled into the binary are used (`fonts/`, Noto Sans under OFL
  1.1); system fonts are never searched, so output is identical on all
  platforms.
- typst-kit font features are **not** enabled (they add 8.6 MB for unused
  serif and math fonts).

The compressed overhead (~10–14 MB) together with the base Tauri app (~3–5 MB)
fits the 25 MB installer budget of NFR-9.

## Consequences

- The installed app is about 33 MB larger on disk.
- Clean CI builds get slower; `rust-cache` mitigates this.
- Scripts beyond Latin, Cyrillic and Greek (needed for Asian countries on the
  roadmap) will require more bundled fonts. We will add them per country and
  measure their size when those countries are added.
- If size becomes a problem, we will revisit option 2 for simple templates.
